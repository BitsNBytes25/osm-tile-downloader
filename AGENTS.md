# Agent Guidelines

This is a simple stand-alone script meant to download map tiles from Open Street Map and Open Topo Map.

## Libraries

When all possible, prefer embedded Python libraries so no virtual environment needs to be maintained.

## Python Version

Python 3.13 is used.

## Coding Style

Use tabs for indentation.

Keep functions simple; once logic inside a function starts to get overly complex, extract the functionality to smaller functions.
